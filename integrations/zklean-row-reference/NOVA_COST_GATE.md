# ZKL-07/08: constraint accounting and the indexed dependent fragment

The preceding native Horn reference needs its own CI. Root-crate CI does not compile the standalone crate. The new workflow runs its own cargo test; a green root job is insufficient.

For the next Nova experiment, pin the existing project's Nova version 0.76.0. Keep this in an optional integration. Scope the first step to a bounded Horn DAG and the next to typed indexed-family rules of the form forall n : Nat, P(n+a) -> Q(n+b). The public rule environment is a set of hypotheses. The receipt proves derivability relative to those hypotheses only. Do not advertise unrestricted theoremhood.

For a fixed depth d, authenticated arity-two append requires four Merkle traversals of d parent hashes each (two premise reads, old empty-slot check, new root update). Rule-table membership, index bits, Boolean selectors, final closure, and domain separation are additional constraints. These are native structural counts, not measured R1CS counts.

Use a pinned field hash and explicitly authenticate each rule row from the environment commitment. Check witness/rule arity and all range constraints inside the step, including cursor < capacity, reference < cursor, equality of the actual index, and correct old/new root. Bind goal, grammar version, rule root, capacity, canonical initial state, and step budget to public parameters. Use constrained terminal and padding states. Never accept an arbitrary intermediate state. Preserve witness privacy as a separate requirement; do not expose private intermediate state or infer privacy from native SHA commitments.

Measure synthesized constraints and variables for depths 4/8/12, arities 0/1/2, and the fixed maximum-arity padded step. In a fixed shape, inactive branches usually still cost constraints, so per-active-rule cost only affects actual proving work if step count or circuit family changes. Report setup, folding, final verification, peak RSS, proof size and public input size separately. Compare a deterministic native trace and actual Nova verifier. Attack wrong statement, rule, arity, index bits, old root, empty slot, final state, and padding transitions. A native hash vector alone is not a zero-knowledge proof.

DataGoblin ZKL-07 measured a proxy objective structural rows + iota steps + 2*premise reads in the original synthetic grammar. It reduced total proxy cost by 30.6% on 128 larger index problems relative to unit proof-tree cost. This weight is provisional and cannot be interpreted as measured Nova constraint savings. Export exact rule-kind counts and fit weights from measured synthesis. For a single uniform Nova step, optimize total number of folded steps first; assess alternative representation, authenticated memory sharing, and multi-shape designs separately. The actual Nova circuit, dependent-typing circuit, and Bitcoin settlement remain outstanding. No Groth16 wrapper is proposed.
