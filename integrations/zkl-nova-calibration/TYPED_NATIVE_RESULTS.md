## Cryptographic value boundary
The native verifier validates the public rule descriptors and public syntax. With the whole rule table public, an ordinary Horn least fixed point also decides derivability directly. Thus this hybrid profile does not establish a speed or privacy advantage over native verification. Its present value is exercising authenticated typed judgment identities, independent source compilation and circuit/Lean conformance. ZKL-17 checked explicit raw conversion in Nova separately; integrating these semantics with typed private term and context openings is a later gate. Do not compare row-only costs against fully constrained substitution circuits as though they represented identical work.
