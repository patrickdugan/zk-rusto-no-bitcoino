The stock Lean exporter (LeanExport.Basic at v4.35.0, format 3.1.0) emits name/level/expression DAGs and dependency-closed declaration groups. inventory.mjs counts unique serialized nodes, declaration kinds, literal/constant/projection references and axioms. It rejects missing declaration references, unknown tags, invalid backward syntax references, wrong format/version and absent roots; for RH it also requires theorem roots and exact permitted axiom subset. It is a diagnostic reader with ordinary JSON.parse (duplicate JSON keys not rejected), not a strict untrusted parser or Lean verifier. It does not prove declaration semantics, axiom dependency minimality, or compare theorem types to an isolated challenge. Full union export includes auxiliary inductive group members. The code's synthetic self-test passed 13 cases in the local tool runtime. Actual RH export has not been generated here.

First actual import: id, Function.const, Function.comp from the pinned Lean Init environment. The upstream definitions are simple lambda/Pi terms. Take universe parameters uniformly at 0 and uniformly at 1, with six registered source specializations. The syntax adapter accepts only closed constant-free terms in Sort/Var/Pi/Lam/App, evaluates concrete universe levels, and rejects other constructs. It records every attempted root. Independent native typing and explicit bulk replay are followed by Lean checking generated definitions and definitional equality to the actual instantiated Init declarations, then Nova synthesis and compressed verification at the fixed 512-slot ZKL-20 profile. Exact statements remain public. The code candidate and workflow are submitted; actual Lean, native import and Nova results pending hosted CI. This deliberately exercises actual Lean export/import without granting unchecked constants or expanding the grammar prematurely. Six source specializations do not establish RH coverage or polymorphic proof verification.

The optional RH inventory job is a bounded diagnostic: pinned cache inputs, source SHA, 2 GiB export limit, time caps, no paid GPU. Cached .olean files are untrusted for theorem correctness; a successful inventory is not kernel replay or independent proof validation. A complete source build/replay and statement comparison against an isolated challenge remain separate gates. Hosted RAM/disk/time may be insufficient for the full closure. Any timeout or missing root fails the job; never relabel partial export as complete.
