# ZKL-16: paired end-to-end transport pilot

Pinned DataGoblin public source e7394fced457c059f20ef54128dbc80b0cc747a5. Four predefined synthetic roots (93000,93001 standard 12-index; 94000,94001 shifted 24-index), two arms per root: exact ordered-height A* and weighted tree DP with shared dependencies. Both replay against original index expressions and independent packed-integer reference before export. Eight cases, not a neural or generalization benchmark.

Fixed Nova 0.76.0 shape: rule table depth 5 (32 slots), proof memory depth 6 (64 slots), maximum arity 2. One public parameter setup and one Spartan/IPA compression setup reused across all cases. The consumer reconstructs the public environment digest, validates all integer fields and references, computes the Poseidon rule root and empty state from the supplied public environment, checks each R1CS assignment and verifies recursive and serialized compressed proofs against those initial states. The host terminal check binds goal and exact step count. Empty rule-table slots are domain-separated and cannot act as rules under the collision-resistance assumption. The source exporter establishes affine normalization and exact reference search in its restricted grammar; the Nova verifier checks derivability relative to the compiled hypotheses. It does not prove the source compiler correct or authenticate an external Lean theorem.

The workflow has CPU and wall-time bounds. It uploads batch, pinned source revision, verified proof binaries, VK, per-case proof hashes and timing receipt. These are public synthetic witnesses only. No private theoremhood, arbitrary Lean kernel, on-chain verification or production security claim. Verification-key authenticity is an external trust requirement. Actual measurements are pending hosted CI; do not quote the older four-rule fixture costs for this shape.
